# ごみ収集カレンダー PWA 設計書

## 1. プロジェクト概要

越谷市第9地区のごみ収集カレンダー（令和8年4月〜令和9年3月）を基に、
スマートフォンで快適に使えるPWAアプリを構築する。

- **対象カレンダー**: 越谷市ごみ収集カレンダー 令和8年度（2026.4〜2027.3）第9地区
- **期間**: 2026年4月1日〜2027年3月31日

## 3. 収集品目と収集パターン

### 3.1 品目一覧

| 品目 | 英語名 | カラー | 出し方 |

| 燃えるごみ | Burnable rubbish | ピンク | 透明または半透明の袋 |

| 古紙類 | Recyclable paper goods | 緑（燃えないごみと同日） | 品目ごとにひもでしばる |
| ペットボトル | Plastic bottles | 紫 | 黄色のカゴ（袋不可） |

| 缶 | Cans | 黄色 | 黄色のカゴ（袋不可） |

## 4. 機能要件

### 4.1 必須機能

| # | 機能 | 説明 |
|---|---|---|
| F-01 | 本日の収集品目表示 | トップ画面に当日収集される品目を大きく表示 |

| F-03 | 月間カレンダー表示 | カラーコードで各品目を視覚的に表示 |
| F-04 | 収集前日プッシュ通知 | 前日夜（20:00）に翌日の収集品目を通知 |
| F-05 | 収集当日朝通知 | 当日朝（7:00）に収集品目を通知 |
| F-06 | オフライン対応 | Service Workerによるキャッシュ、オフライン閲覧可能 |
| F-07 | ホーム画面インストール | Add to Home Screen対応のPWA |

### 4.2 追加機能

| # | 機能 | 説明 |
|---|---|---|
| F-08 | ごみ分別検索 | 品目名で分別方法を検索 |
| F-09 | 出し方ガイド | 各品目の詳細な出し方を表示 |
| F-10 | 粗大ごみ情報 | 粗大ごみの料金・予約方法を表示 |

### 6.3 P-02: カレンダー画面

- 月間カレンダー形式
- 各日付セルに収集品目をカラーバッジで表示

### 8.2 Service Worker キャッシュ戦略

| リソース種別 | 戦略 |
|---|---|
| HTMLシェル | Cache First |
| JS/CSSアセット | Cache First（ハッシュ付き） |
| 収集スケジュールJSON | Cache First（初回キャッシュ後はオフライン可） |
| アイコン画像 | Cache First |

### 8.3 プッシュ通知フロー

1. ユーザーが設定画面で通知を許可
2. Service WorkerがPush通知の購読を登録
3. 前日20:00 / 当日7:00にService WorkerのBackground Sync（もしくはScheduled Task）で通知を送信

> ※ バックエンドサーバーが不要なアーキテクチャを優先する。
> Web Push APIには通知サーバーが必要なため、代替として Notification API +
> Service Worker の setInterval / alarm を使ったローカル通知を実装する。
